# Property Law Starter

A minimal single-page React site for a property law practice: hero image, about section, and a short list of recent work.

## Run it

```
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Edit content

Everything lives in `src/App.jsx` — the property list is a plain array at the top of the file, and the about text is inline in the JSX. Styles are in `src/App.css`.
